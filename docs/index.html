          Cómo está hecho

          Un mostrador local, publicable como página estática.

          1. Navegador Conversación, micrófono y voz. En GitHub Pages solo vive esta capa.
          2. Python Valida la ficha, guarda el JSON y decide cuándo pedir confirmación.
          3. Ollama llama3.2 redacta la respuesta en tu máquina. Nada se envía a un proveedor.
          4. Notas Garantía, plazos y seguridad se buscan por palabras, sin otro modelo.

          GitHub Pages no puede ejecutar Python ni Ollama. Esta URL enseña un encargo de ejemplo y la arquitectura. Para hablar con Mara, en el ordenador donde corre Ollama: python serve.py y abre http://127.0.0.1:8765.
