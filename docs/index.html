          How it is built

          A local desk that can also be published as a static page.

          1. Browser Chat, microphone, and voice. On GitHub Pages, only this layer is served.
          2. Python Validates the ticket, saves the JSON, and decides when to ask for confirmation.
          3. Ollama llama3.2 writes the reply on your machine. Nothing is sent to a provider.
          4. Notes Warranty, timing, and safety are found by words, without a second model.

          GitHub Pages cannot run Python or Ollama. This URL shows an example request and the architecture. To talk to Mara, on the computer where Ollama runs: python serve.py and open http://127.0.0.1:8765.
